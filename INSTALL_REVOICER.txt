DZOD Revoicer - установка (Windows 10/11, 64 бит)

DZOD Revoicer - перепевка вокала вашим вокалистом DZOD. Работает сам по себе и из DZOD Studio
(кнопка DZOD Revoicer в Block Vocals). Вокалиста (модель голоса) делает DZOD Vocalist.

1. Программа
  Запустите DZOD-Revoicer-<версия>-setup.exe. Права администратора не нужны.
  Ярлык появится на рабочем столе и в меню «Пуск».
  Программа не подписана цифровой подписью, поэтому Windows может показать
  окно «Система Windows защитила ваш компьютер»: нажмите «Подробнее» -> «Выполнить в любом случае».

2. Движок (один раз)
  При первом запуске откроется вкладка «Движок».
  Проверьте папку (по умолчанию D:\DZOD_Revoicer; без пробелов и русских букв)
  и нажмите «Установить движок». Программа сама скачает около 11 ГБ
  (Applio, PyTorch для NVIDIA, нейросети чистки). Это 20-60 минут, прерывать можно.
  Движок у DZOD Revoicer свой и от DZOD Vocalist не зависит.

3. Вокалист
  В DZOD Vocalist: вкладка «Голос» -> кнопка «Сохранить вокалиста в папку…»
  (получится папка, например «Голос 1», с моделью, индексом и voice.json).
  В DZOD Revoicer: вкладка «Перепевка» -> «Загрузить вокалиста (папка)…» -> выбрать эту папку.
  Подойдёт и любая папка с готовой моделью RVC (.pth и .index).

4. Работа
  Откройте вокал (или нажмите DZOD Revoicer в DZOD Studio на выбранном Slice),
  почистите, перепойте, сравните дубли.
  «Вставить в Studio» / «Рядом с исходником» - файл ляжет в папку исходника с новым именем:
  RIGOR 04 Vocal.wav -> RIGOR 04 Vocal_Resinger01.wav (дальше _Resinger02 ...).

Если окно программы не открывается
  Нужен компонент Microsoft Edge WebView2 (в Windows 11 и обновлённой Windows 10 он уже есть).
  Журнал работы и ошибок: %LOCALAPPDATA%\DZOD Revoicer\log.txt
