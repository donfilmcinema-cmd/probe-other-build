DZOD Vocalist - установка (Windows 10/11, 64 бит)

1. Программа
  Запустите DZOD-Vocalist-<версия>-setup.exe. Права администратора не нужны.
  Ярлык появится на рабочем столе и в меню «Пуск».
  Программа не подписана цифровой подписью, поэтому Windows может показать
  окно «Система Windows защитила ваш компьютер»: нажмите «Подробнее» -> «Выполнить в любом случае».

2. Движок (один раз)
  При первом запуске откроется вкладка «Движок».
  Проверьте папку программы (по умолчанию D:\DZOD_Vocalist; без пробелов и русских букв)
  и нажмите «Установить движок». Программа сама скачает около 12 ГБ:
  Applio 3.6.6, PyTorch для видеокарт NVIDIA и модели. Это 20-60 минут.
  Установку можно прервать и продолжить позже - скачанное не пропадёт.
  Перед установкой стоит обновить драйвер видеокарты NVIDIA.

3. Вокалист для DZOD Revoicer / DZOD Studio
  Вкладка «Голос» -> выбрать голос -> «Сохранить вокалиста в папку…».
  Получится папка с именем голоса (модель .pth, индекс .index, voice.json) -
  её загружают в DZOD Revoicer кнопкой «Загрузить вокалиста (папка)…».

Если окно программы не открывается
  Нужен компонент Microsoft Edge WebView2 (в Windows 11 и обновлённой Windows 10 он уже есть).
  Без него интерфейс откроется во вкладке обычного браузера - работать можно и так.
  Журнал работы и ошибок: %LOCALAPPDATA%\DZOD Vocalist\log.txt
