Обучение модели

          

          

            
Частота
              
              48 кГц — для пения, чище верх. Меньше — только если обучение не помещается в память.

            
Эпох всего
              Эпоха — один проход по всем фразам. Для 30–60 минут обычно хватает 200–400.

            
Сохранять каждые
              Через сколько эпох сохранять копию модели — из них потом выбирают лучшую.

            
Размер пачки
              Сколько кусков учится за раз. Для 12 ГБ видеопамяти — 8; при ошибке памяти — 4–6.

          

          
          

            
            
          

          

          

            Почему эпохи сохраняются по ходу. Слишком долгое обучение даёт жёсткий, «металлический» звук,
            поэтому последняя эпоха не всегда лучшая. Её выбирают на слух на шаге 3 «Эпохи» — можно не дожидаться
            конца обучения. Остановить можно в любой момент: сохранённые эпохи останутся, обучение можно продолжить.
          

        

      


      
      

        

          
Сравнить эпохи

          
Один и тот же отрывок (~25 секунд) перепевается голосом каждой отмеченной эпохи.
            Потом слушаете их по очереди с того же места и делаете лучшую основной — её программа
            будет использовать на шаге «Песня».

Перепевка голосом DZOD

      
Откройте вокал из Suno — программа очистит его и перепоёт голосом вашей модели.
        Готовый дубль ложится новой Line в Block Vocals DZOD Studio, с начала песни.

      

        
1. ИсходникВокальный стем из Suno (лучше WAV) или полный трек.

        
2. ЧисткаОтделить бэки, убрать ревер, по желанию — шум.

        
3. ПерепевкаВыбрать голос и настройки, сравнить с исходником.
